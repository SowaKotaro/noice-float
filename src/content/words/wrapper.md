engineer:
  spelling: "wrapper"
  levels:
    - "既にあるものを包んで、使いやすくした薄い皮。"
    - "外部のライブラリや API を包み、自分たちの都合のいい形で呼べるようにした層。中身は元の呼び出しに渡すだけで、引数の整形やエラーの言い換えだけを担う。乗り換えたくなったとき、直す場所がここ一か所で済むのが利点。"
    - "既存の実装を包んで別のインターフェースを与える層（アダプタや facade と重なる）。外部 SDK をあちこちから直接呼ぶと差し替え時に全面改修になるので、境界にラッパーを一枚置いて依存を集める。厚くしすぎると元の機能に手が届かなくなるため、包むのは呼び出し規約だけにして振る舞いはそのまま通すのが原則。"
  examples:
    - "SDK を直接呼ばずにラッパーを挟もう"
    - "この関数、ただのラッパーだよ"
    - "ラッパー越しに叩いて"
